# MPK-Revival Preset Backups

This directory contains pristine backups of your Akai MPK49 presets:
- `raw/`: Verbatim `.syx` binary SysEx dump files straight from the hardware.
- `json/`: Human-readable and structured JSON representations containing metadata, timestamp, extracted strings, and raw byte arrays.

## Safety Protocol
1. Never overwrite raw dumps.
2. Label filenames with timestamp and preset name (e.g. `2026-09-20_preset01_ableton.syx`).
