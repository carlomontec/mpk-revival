# MPK-Revival 🎹⚡️

> Bringing the legendary **Akai MPK49** into the modern music production era.

A modern, zero-install Web MIDI Editor, SysEx Librarian, and DAW integration toolkit for the Akai MPK49 (plus support for MPK25, MPK61, and MPK88).

---

## Why MPK-Revival?

The Akai MPK49 has phenomenal hardware—semi-weighted keys, heavy-duty MPC pads, endless rotary encoders, and responsive faders. However, the original **Vyzex MPK49** editor software is a 32-bit legacy utility from the Windows XP / Mac OS X 10.5 era that has been abandoned and does not work on modern 64-bit operating systems.

**MPK-Revival** gives your MPK49 a second life:
- 🌐 **Modern Web MIDI Preset Editor**: Runs in any modern browser (Chrome, Edge, Opera, Brave) without installing drivers or software.
- 🔄 **SysEx Librarian**: Backup, edit, inspect, and transmit presets directly to/from the keyboard memory slots (1–30).
- 🎛️ **DAW Templates & Control**:
  - **Reason 14**: Dedicated Remote Codecs & Remote Maps taking full advantage of the updated Reason Rack, Combinators, and Mixer.
  - **Ableton Live (MPK49++)**: Modern Python 3 control scripts with session focus ring (Red Box) and APC-style mixer control.
